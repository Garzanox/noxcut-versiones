# NoxCut: versiones

Instaladores de NoxCut, el editor de vídeos verticales con subtítulos palabra a palabra.

- **Windows:** `NoxCut-instalador.exe`
- **Mac:** `NoxCut-mac.zip` (NoxCut.app)

Bájalos de [la última versión](https://github.com/Garzanox/noxcut-versiones/releases/latest). Hace falta una licencia para usarlo.
Si ya tienes NoxCut, no hace falta bajar nada: al abrirlo te avisa de cada versión nueva y se actualiza con un click.
